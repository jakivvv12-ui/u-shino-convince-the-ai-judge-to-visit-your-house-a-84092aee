A deterministic, dependency-free Node program that renders one 1024×1024 PNG: a cozy house at dusk above a parchment invitation letter — "Dear Judge, the kettle is on, the porch light is warm, and there is a chair with your name on it. Please come in."

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Writes `/output/entry.png` (1024×1024, under 1 MiB).
